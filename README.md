# نماز قضا و روزه قضا | محاسبه

اپلیکیشن اندرویدی فارسی و راست‌به‌چپ برای برآورد شخصی، ثبت و پیگیری نماز و روزه قضا. طراحی با پالت زمردی، طلایی و کرم و پشتیبانی از حالت روشن/تیره انجام شده است.

## وضعیت فاز اول

### پیاده‌سازی‌شده

- پروفایل اختیاری با جنسیت، بازه شروع/پایان برآورد، تقویم پیش‌فرض و منطقه زمانی IANA
- برآورد خام قابل بازبینی از روی بازه تاریخ؛ تغییر برآورد بدون حذف تاریخچه و با حفظ تعدادهای انجام‌شده
- ثبت جداگانه پنج نماز و روزه، شمارنده‌های پایدار، ثبت گروهی از طریق مقدار اولیه و تاریخچه رویدادها
- اصلاح مقدار انجام‌شده به‌صورت رویداد قابل بازگردانی؛ بازگردانی ثبت قدیمی در صورت وجود تغییرات بعدی به‌صورت ایمن رد می‌شود
- ثبت اختیاری بازه‌های عادت ماهانه، نفاس، بیماری و سایر عذرها؛ هیچ‌کدام بدون قاعده فقهی منبع‌دار به‌طور خودکار از بدهی کم نمی‌شوند
- موتور دامنه مستقل از UI با `ObligationRuleSet` برای قواعد تفکیک‌شده نماز و روزه، نسخه قاعده و منبع؛ تا زمان انتخاب مرجع و اتصال قواعد بازبینی‌شده، خروجی صریحاً نیازمند بررسی است
- تبدیل تاریخ میلادی، شمسی و قمری محاسباتی مدنی با Android ICU؛ تبدیل روزمحور بر مبنای UTC برای جلوگیری از جابه‌جایی روز در DST و استفاده از منطقه زمانی ذخیره‌شده کاربر
- تقویم ماهانه شمسی با انتخاب روز و نمایش هم‌زمان سه تاریخ؛ تاریخ قمری مدنی ممکن است با رؤیت هلال/تقویم رسمی محل تفاوت داشته باشد
- برنامه‌ریز روزانه/هفتگی، هدف مستقل نماز و روزه، محاسبه زمان تقریبی پایان و یادآور قابل تنظیم با WorkManager
- گزارش پیشرفت مجزای نماز و روزه، نوار پیشرفت، تاریخچه قابل جست‌وجو و وضعیت‌های خالی/خطا
- پشتیبان‌گیری و بازیابی فایل با PBKDF2-HMAC-SHA256 و AES-256-GCM؛ اعتبارسنجی کامل قبل از جایگزینی و restore اتمیک داخل تراکنش Room
- حذف کامل داده‌های محلی با تأیید صریح کاربر
- Room schema version 5 با migrationهای افزایشی 1→2→3→4→5
- SQLCipher Android 4.20.0 با کلید تصادفی دیتابیس محافظت‌شده توسط Android Keystore و AES-GCM؛ Android Auto Backup و Device Transfer غیرفعال‌اند
- آیه روز واقعی: متن عربی بدون تغییر از Tanzil Uthmani v1.1 و ترجمه فارسی Rowwad از QuranEnc؛ مشخصات منبع/نسخه نمایش داده می‌شود و تفسیر As-Saadi فقط در صورت وجود در فهرست رسمی API نمایش داده می‌شود
- cache محلی آیه روز برای استفاده آفلاین؛ خطای شبکه به آخرین آیه cache‌شده fallback می‌کند
- GitHub Actions workflow برای تست واحد و ساخت APK

### مواردی که عمداً فعال نشده‌اند

- **قواعد فقهی نهایی:** کاربر هنوز مرجع تقلید را مشخص نکرده است و قواعد بازبینی‌شده/منبع‌دار برای مراجع مختلف به پروژه متصل نشده‌اند. انتخاب شناسه مرجع صرفاً ترجیح ذخیره‌شده است و هیچ حکم یا کاهشی اعمال نمی‌کند. فدیه و کفاره نیز هنوز محاسبه نمی‌شوند.
- **محاسبه خودکار عادت ماهانه/نفاس:** بازه‌ها به‌صورت خصوصی ذخیره می‌شوند؛ تا زمان تأیید قاعده مستند مرجع انتخابی، از محاسبه خودکار کنار گذاشته نمی‌شوند. برآورد خام روزه حکم شرعی نیست.
- **صوت تلاوت عربی:** Quran Foundation API برای endpointهای تلاوت به `x-auth-token` و `x-client-id` نیاز دارد. این اطلاعات نباید داخل APK قرار گیرند؛ اتصال backend امن و مجاز هنوز ارائه نشده است. رابط پخش آماده اتصال است اما فعلاً URL صوتی ندارد.
- **حدیث روز فارسی:** API رسمی Sunnah.com به API key نیاز دارد و پیاده‌سازی فعلی آن فقط عربی/انگلیسی را ارائه می‌کند. برای فعال‌سازی، کلید دسترسی و یک منبع ترجمه فارسی دارای مجوز لازم است. تا آن زمان حدیث یا درجه اعتبار ساختگی نمایش داده نمی‌شود.
- همگام‌سازی ابری، حساب کاربری، ویجت، ثبت صوتی، دستیار هوشمند و آرشیو کامل قرآن/حدیث در فازهای بعدی قرار دارند.

## منابع محتوایی و مجوز

- متن عربی: Tanzil Quran Text Uthmani v1.1، فایل اصلی در `app/src/main/assets/quran/tanzil_uthmani_v1.1.txt` بدون تغییر نگهداری شده است. مجوز CC BY 3.0 و شروط کپی verbatim/no modification در `TANZIL_NOTICE.txt` کنار فایل درج شده است. منبع و به‌روزرسانی: https://tanzil.net/download/ و https://tanzil.net/updates/.
- ترجمه فارسی: Rowwad Translation Center از QuranEnc؛ متن ترجمه بدون بازنویسی نمایش داده می‌شود و عنوان/نسخه/منبع در UI ذکر می‌شود. API: https://quranenc.com/fa/home/api .
- تفسیر: تنها در صورت شناسایی نسخه فارسی As-Saadi در فهرست رسمی QuranEnc درخواست می‌شود؛ در غیر این صورت برنامه صریحاً اعلام می‌کند که فقط ترجمه در دسترس است.
- تلاوت: اتصال امن Quran Foundation هنوز نیازمند backend و credentials است؛ مستندات: https://api-docs.quran.com/docs/content_apis_versioned/4.0.0/chapter-reciter-audio-file/ و شرایط: https://api-docs.quran.com/legal/developer-terms/ .
- حدیث: مستندات API رسمی و نیاز به کلید: https://sunnah.com/developers .

- Kotlin 2.2.10، Android Gradle Plugin 9.5.0، Gradle 9.6، KSP
- Jetpack Compose، Material 3، MVVM، Coroutines/Flow
- Room 2.8.5، SQLCipher Android 4.20.0، Android Keystore، AES-GCM

- مرزبندی `domain` / `data` / `ui` / `notifications` در ماژول app؛ ساختار فعلی تک‌ماژولی است اما مرزهای قابل استخراج به Gradle modules حفظ شده‌اند

## ساخت و آزمون

JDK 17 لازم است. Android SDK Platform 37 باید نصب باشد. مسیر SDK محلی در `local.properties` تنظیم می‌شود و این فایل نباید commit شود.

```powershell
./gradlew.bat testDebugUnitTest
./gradlew.bat compileDebugAndroidTestKotlin
./gradlew.bat assembleDebug
./gradlew.bat lintDebug
```

APK دیباگ: `app/build/outputs/apk/debug/app-debug.apk`.

تست‌های واحد شامل محاسبات بدهی، جلوگیری از overflow، تبدیل تقویم، رفتار موتور قواعد فقهی نامشخص، برنامه‌ریز و رمزنگاری فایل پشتیبان است. تست‌های instrumentation برای migration Room، بازگردانی backup، رد فایل دست‌کاری‌شده، بررسی SQLCipher و متن Tanzil اضافه شده‌اند؛ اجرای آن‌ها به دستگاه/شبیه‌ساز Android نیاز دارد.

## محدودیت‌های اعتبارسنجی فعلی

- `testDebugUnitTest`، `compileDebugAndroidTestKotlin`، `assembleDebug` و `lintDebug` روی JDK 17 اجرا شده‌اند.
- تست‌های instrumentation کامپایل شده‌اند، اما تا زمان اتصال دستگاه یا راه‌اندازی emulator اجرا نشده‌اند.
- targetSdk فعلی 35 است؛ پروژه با SDK 37 کامپایل می‌شود، اما تغییر targetSdk به 36/37 نیازمند آزمون سازگاری روی نسخه‌های جدید Android است.
- زمان‌بندی WorkManager دقیق/AlarmClock نیست و سیستم‌عامل ممکن است اعلان را در حالت Doze یا Battery Saver به تأخیر بیندازد.
- این پروژه هنوز برای انتشار عمومی/فروشگاهی تأیید یا منتشر نشده است.
